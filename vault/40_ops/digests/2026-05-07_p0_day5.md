# Polaris P0 Day 5 — Venue adapters full + paper loop smoke + dashboard v0

## Scope
- OKX adapter full: signing.py (HMAC-SHA256, demo flag) + trade endpoints
  (place_market_order IOC + cancel + balance + positions + orders-pending +
  fill query) + constraint_translator (lotSz / minSz / tickSz fetch).
- Capital adapter full: session.py (CST + X-SECURITY-TOKEN, 9-min anti-idle
  ping, 401 auto-refresh, 1/s rate cap) + lifecycle (open / workingorder /
  close / list / confirm) + constraint_translator (min_deal_size / step /
  leverage from `/markets/{epic}`).
- `polaris/core/data/fill_normalizer.py` — unified Fill dataclass +
  `normalize_okx_fill` + `normalize_capital_confirm` (with leverage param).
- `polaris/scripts/smoke_paper_loop.py` (519 LOC) + helper splits
  (`_smoke_fills.py`, `_smoke_real_probes.py`, `_smoke_haiku_stub.py`).
- `polaris/scripts/dashboard_v0.py` — terminal panels (universe, positions,
  cell distribution, learner state, recent fills, daily PnL).
- 5 new test files: test_okx_adapter (19), test_capital_adapter (13),
  test_fill_normalizer (8), test_paper_loop_smoke (8), test_dashboard_v0 (5).

## Codex external review (2026-05-07 medium reasoning)
- **P1 fixed**: `_parse_capital_ts` was returning host-tz seconds for naive
  ISO strings. Forced UTC explicitly (regression test added).
- **P1 fixed**: `normalize_capital_confirm` did not include leverage in
  `size_usd` (CFD gross notional under-reported by leverage factor for
  non-1:1 epics). Added `leverage: float = 1.0` parameter (regression test
  added: 1 lot × $10 pip × 30 leverage = $300).
- **P2 deferred**: `update_baseline_from_bars` two-pass iterator issue is
  Day-1 code; logged for Day 6 P1 sprint follow-up.

## Aggressive bias preserved
- IOC px clamp at +5 bps (R2 max slippage) for OKX SPOT entries.
- Capital `forceOpen=True` so simultaneous BUY/SELL exposures are kept
  separate (no auto-close hedging).
- Smoke loop runs all 7 strategies × 4 focus entries on every tick — no
  pre-filter dampening.

## Risks / known limitations
- Capital `close_position` returns `status=PENDING` from REST — full CLOSED
  state confirms via `/confirms/{ref}` (smoke loop currently records the
  PENDING reply; Day 6 should poll confirm to reach CLOSED).
- `_validate_signal` only runs G3 — full pipeline (G4-G7) needs sized
  `signal_intent` + `risk_state` + `portfolio` payloads (Day 6 plumbing).
- Dashboard reads from sqlite read-only; race-free but `recent_fills`
  currently reads `orders` table (P0 surrogate; Day 6 will add `fills` table).

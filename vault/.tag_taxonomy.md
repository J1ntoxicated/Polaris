# .tag_taxonomy — Polaris Vault 태그 표준

> `tools/vault_lint.py` 가 이 파일에 정의되지 않은 태그 사용 시 warn.

## 1. status (모든 ADR/INSIGHT/HYPOTHESIS 필수)

- `#status/active` — 현재 유효, 적용 중
- `#status/applied` — ADR 적용 완료
- `#status/proposed` — ADR 제안 (max 7일, 초과 시 자동 폐기 또는 ack 강제)
- `#status/provisional` — codex-debate 통과, Jin ack 대기
- `#status/superseded` — 다른 ADR/INSIGHT가 대체
- `#status/expired` — 만료 (lifecycle 자동 관리)
- `#status/archived` — 60_alpha 가설 폐기 또는 실패

## 2. scope

- `#scope/spot` — SPOT 거래 영역
- `#scope/vault` — vault 운영
- `#scope/harness` — 하네스 (.claude/)
- `#scope/alpha` — 알파 가설/검증
- `#scope/data` — DB/state
- `#scope/external` — 외부 advisor (codex/gemini)

## 3. priority

- `#priority/p0` — 즉시 처리 (보통 active critical)
- `#priority/p1` — 7일 이내
- `#priority/p2` — 30일 이내
- `#priority/p3` — 백로그

## 4. editable (Authority 분리 P1)

- `#editable/true` — Jin 또는 권한 agent 편집 가능
- `#editable/false` — read-only (자동 생성 또는 derived view)

## 5. mode (작업 모드 매핑)

- `#mode/dev` — DEV 모드 산출물
- `#mode/alpha` — ALPHA 모드 산출물
- `#mode/forensic` — FORENSIC 모드 산출물
- `#mode/debate` — DEBATE 모드 산출물
- `#mode/meta` — 메타/운영 (constitution/index/log)

## 6. reviewed-by (Jin mandate)

- `#reviewed-by/codex` — codex 외부 리뷰 통과 (40_components/code 변경 노트 의무)
- `#reviewed-by/jin` — Jin 직접 ack
- `#reviewed-by/none` — 미리뷰 (warning)

## 7. type

- `#type/insight` — INSIGHT 노트
- `#type/adr` — ADR 노트
- `#type/lesson` — lesson 노트
- `#type/hypothesis` — 가설 노트
- `#type/component` — 컴포넌트 노트
- `#type/pattern` — 패턴 카탈로그
- `#type/constitution` — 헌법 노트 (10_constitution/)

## 8. polaris (전역)

- `#polaris` — Polaris 프로젝트 노트 (모든 vault 노트 의무)

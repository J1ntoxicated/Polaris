# 레짐 감지 — 시장 상태 분류 지침

## 핵심 개념
시장 레짐은 현재 시장이 어떤 상태에 있는지를 분류한 것이다. 5개 상태(RISK_ON, RISK_OFF, TRANSITION, NEUTRAL, CRISIS)가 존재하며, 각 자산 그룹(CRY/FX/STK/CMD/IDX)은 독립적인 레짐을 갖는다.

레짐이 중요한 이유: 포지션 사이징, 시그널 가중치, 진입/청산 파라미터가 모두 레짐에 따라 동적으로 변한다. 잘못된 레짐 판단은 전체 트레이딩 파이프라인의 의사결정을 왜곡한다.

구조적 특징:
- 크립토 감지기와 매크로 감지기가 독립 작동
- 글로벌 위기 에스컬레이션 레이어가 두 감지기를 즉시 오버라이드 가능
- 히스테리시스(연속 확인)로 레짐 플래핑 방지 (CRISIS는 즉시 적용)
- 트레이드 결과에 따른 임계값 자가 학습

## 분석 방법론
레짐 분석 시 다음 관점으로 접근:

1. **입력 데이터 품질**: 각 감지기에 들어가는 입력값(F&G, 펀딩율, OI, ADX, VIX, HY스프레드, MOVE 등)이 실제로 유효한 값인지, 디폴트 폴백에 의존하고 있지는 않은지 확인
2. **임계값 적정성**: 현재 임계값이 최근 시장 환경을 잘 반영하는지, 자가학습이 올바른 방향으로 조정하고 있는지 검증
3. **위기 에스컬레이션 정확도**: 글로벌 위기 트리거가 너무 민감하거나 둔감하지 않은지 평가
4. **레짐별 파라미터 효과**: 각 레짐에서의 사이징 배수, 시그널 가중치 변경이 실제 트레이드 성과에 긍정적 영향을 주는지 분석

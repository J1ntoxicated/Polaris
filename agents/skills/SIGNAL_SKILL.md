# 시그널 엔진 — 복합 스코어링 지침

## 핵심 개념
시그널은 개별 데이터 소스에서 도출된 매매 방향 제안이다. 다수의 시그널 프로바이더가 각자 점수를 산출하고, CompositeScorer가 가중 합산하여 최종 복합 점수를 만든다.

핵심 설계 원칙:
- **컨트라리안 리맵**: 중간 강도 시그널을 부스트하고 극단 시그널을 감쇠 — 과열된 컨센서스를 역이용
- **다중 게이트 필터**: 복합 점수를 통과한 시그널만 진입 파이프라인으로 진행
- **자산 그룹별 활성 프로바이더**: 크립토는 전체, 비크립토는 관련 프로바이더만 활성
- **품질 자가조정**: 프로바이더별 승률 추적 → 가중치 자동 조절

## 분석 방법론
시그널 품질 평가 시 다음 관점으로 접근:

1. **프로바이더별 승률 추적**: 각 프로바이더가 실제 트레이드 수익에 기여하는 정도 측정. 승률이 낮은 프로바이더의 가중치가 적절히 감소하고 있는지 확인
2. **가중치 균형**: 특정 프로바이더에 과도한 의존이 없는지, 플랫폼(OKX/Capital)별 가중치 차이가 합리적인지 검토
3. **게이트 통과율**: 각 게이트에서 거부되는 비율 분석 — 특정 게이트가 과도하게 차단하면 기회 손실, 너무 느슨하면 품질 저하
4. **컨트라리안 리맵 효과**: 리맵 전/후 점수 분포가 실제 성과와 상관관계가 있는지 검증
5. **시간 감쇠**: 오래된 시그널의 감쇠가 적절한지, TTL 설정이 합리적인지 평가

## 고도화 방향
- 새로운 시그널 소스 탐색 (온체인 데이터, 소셜 센티먼트 등) — `/research` 활용
- 프로바이더 가중치 최적화 — `/debate` 또는 `/grid-search` 활용
- 비활성 프로바이더(cross_exchange, macro_regime, institutional) 데이터 소스 확보 후 활성화 검토
- 게이트 임계값 동적 조정 — 시장 상황에 따라 게이트 엄격도 자동 변경
- 베이지안 예측기 정확도 향상

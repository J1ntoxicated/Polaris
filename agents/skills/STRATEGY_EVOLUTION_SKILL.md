# 전략 진화 — 토너먼트 + 유전 알고리즘 지침

## 핵심 개념
전략 진화는 유전 알고리즘으로 트레이딩 전략을 자동 개선하는 시스템이다.

핵심 구성요소:
- **Elo 토너먼트**: 체스 레이팅 방식으로 전략 간 상대 성과 비교 — 트레이드 수, 수익률, 안정성 등 다차원 평가
- **3가지 변이**: Gaussian(랜덤 탐색), Bayesian(엘리트 교차), AI-Targeted(AI 제안 변이)
- **소프트맥스 라우팅**: 레짐별 탐색/착취 온도 조절 — 위기 시 더 공격적 탐색
- **ParamOrchestrator**: 레짐 변경 시 파라미터 즉시 교체 + 적응형 튜닝

설계 철학: 초기 세대는 랜덤 탐색 비중이 높고, 세대가 진행될수록 AI 기반 정밀 변이 비중 증가. 최약 전략은 자연 도태(Elo 바닥 도달 시 비활성화).

## 분석 방법론
전략 진화를 분석할 때 다음 관점으로 접근:

1. **Elo 분포**: 전략들의 Elo 분포가 건강한지 — 모든 전략이 한 곳에 몰리면 다양성 부족, 너무 퍼지면 품질 격차
2. **변이 효과**: 각 변이 타입(Gaussian/Bayesian/AI)이 생산하는 자식 전략의 생존율과 성과 비교
3. **토너먼트 공정성**: 트레이드 수가 적은 신규 전략이 보호받고 있는지, 충분한 데이터 후 평가되는지
4. **세대별 개선**: 세대가 진행될수록 평균 fitness가 향상되는지 추적
5. **자산 그룹별 균형**: 특정 그룹에 전략이 과도하게 집중되거나 부족하지 않은지

## 고도화 방향
- 더 나은 fitness 함수 설계 — `/debate`로 가중치 구성 최적화
- 새로운 변이 방법 탐색 (교차 검증 기반, 시장 레짐 특화 등)
- 전략 다양성 강제 메커니즘 — 너무 유사한 전략 간 페널티
- AI 변이 품질 향상 — 더 정교한 프롬프트, 과거 성공/실패 패턴 활용
- 그룹 간 전략 이식 가능성 탐색 (크립토 성공 전략 → 포렉스 적용)

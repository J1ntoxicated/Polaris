# P0 Day 2 — Layer 7 + Layer 4 + Capital proxy digest

## What landed

- **Layer 7 (Strategy Isolation Primitives)**: `polaris/core/isolation/`
  - `circuit_breaker.py` — 4-state machine (ACTIVE / SOFT_HALT / HARD_HALT / RISK_ONLY) with **monotonic severity** (SOFT cannot downgrade open HARD/RISK_ONLY) + auto-expiring SOFT (15 min) + manual reset for HARD.
  - `allocator_fence.py` — single global `asyncio.Lock` over a SQLite reservation ledger (TTL 5 s); process-wide singleton helper `get_process_fence` guards against accidental multi-instance bypass.
  - `worker.py` — supervisor + `run_strategy_task` with **RISK_ONLY exit hook** (`tick_risk_only`) so HALT does not strand active positions.
  - `namespace.py` — `strategy_id`-scoped helpers over unified tables (no per-strategy DB split).
  - `order_keys.py` — canonical idempotent key + payload-hash dedupe; same-key + different-payload raises `IdempotencyConflictError` and records a fault row.
- **Layer 4 (Cell Matrix)**: `polaris/core/cell_matrix/`
  - 4-dim primary table + parent3 + parent2 + shadow context.
  - T11 score `avg_pnl_r × √n_eff / 70`, EWMA 7-day half-life, warmup shrinkage 5 ≤ n_eff < 20 with parent3 → parent2 → 0 fallback.
  - Dynamic quartile activation gate (≥ 20 eligible cells) with **read-time decay** (`load_eligible_scores_decayed`) so stale winners drop out of the pool.
  - SSOT: `resolve_routing_for_cell` composes cell + parent reads + decay + blend + quartile classification.
- **Layer 3 sizing skeleton (ADR-005 T4 seam)**: `polaris/core/sizing/cell_mult_application.py`
  - `apply_cell_routing_mult` is the *only* production caller of the L4 SSOT — guarantees the warmup/decay path can never be silently bypassed.
- **Capital CFD vol/depth proxy**: `polaris/venues/capital/market_proxy.py`
  - `vol_24h_proxy` = Σ(close × volume) over 24 HOUR candles via `/api/v1/prices/{epic}`.
  - `depth_proxy` = (1/spread_bps) × atr_pct × asset-class pip notional × 10 000.
  - 4-axis filter accepts a Capital row when **either** proxy clears its floor (`vol ≥ $30M` OR `depth ≥ $500k`).
  - Asset-class ATR floor (`crypto 2.0 / forex 0.3 / indices 0.4 / commodity 0.5`) so FX/indices are not excluded by the crypto-tuned default.
- **Schema additions**: `cell_matrix_p0/parent3/parent2/shadow`, `strategy_halts`, `strategy_fault_events`, `allocator_reservations` (+ unique partial index on order_key), `order_intents`, `positions`, `orders`, `risk_events`.

## Codex external review

- **Round 1** (gpt-5.4): REJECT — 4 P0 blockers
  1. warmup shrinkage was dead code (no production caller), 2. EWMA decay not applied at read time + parent score decay was linear (must be √factor for T11), 3. circuit-breaker non-monotonic (SOFT could downgrade HARD), 4. RISK_ONLY skipped tick entirely (spec says exit-only path).
- **Round 2**: REJECT — `resolve_routing_for_cell` SSOT still had no production caller (only smoke).
- **Round 3**: **APPROVE** — Layer 3 sizing skeleton (`apply_cell_routing_mult`) wires the SSOT into the production path; warmup regression test now asserts the end-to-end routing decision; `load_eligible_scores` marked observability-only.

## Aggressive-bias self-check

- Routing top mult **×1.5** preserved (ADR-005 patch); bottom **×0.5** (no ×0.3 — loser cells need recovery samples).
- Warmup blend never floors negative parents — losers stay losers, winners stay winners until they earn calibrated trust (n_eff ≥ 20).
- Capital proxy is OR-gate, not strict — a venue that publishes only depth (or only vol) still enters the active universe.
- RISK_ONLY allows exit/stop-update so a halted strategy does not strand its open positions in market drawdown.
- Circuit breaker monotonic severity prevents an attacker / bug from silently downgrading a HARD halt to SOFT and re-entering after 15 minutes.

# P0 Day 4 — Layer 5 Learner + Layer 6 Live Recalc Stub + 7 Strategies digest

## What landed

- **Layer 5 — Learner Network** (3 P0 priority learners, ADR-007): `polaris/core/learners/`
  - `base.py` — `BaseLearner` ABC: incremental `update(trade)` + `get_mult(triple)` +
    atomic `commit_hourly()` + `rollback(snapshot_ts)`. Embedded clip helpers
    (`clip_individual_mult [0.3, 3.0]`, `clip_product_mult [0.1, 5.0]`,
    `clip_hourly_delta ±0.1`) and `resolve_final_size_mult` (independent
    multiplicative axis composition).
  - `session.py` — `SessionMultLearner` keyed on `<strategy>:<session>`,
    WR≥55% → +0.1 / WR≤40% → −0.1.
  - `regime.py` — `RegimeMultLearner` keyed on `<strategy>:<regime>` + SSOT
    for adaptive_learner_attack triple block emission (`(ticker × strategy ×
    regime)` registry, 1h auto-unblock, `size_mult=0.3`).
  - `max_hold.py` — `MaxHoldLearner` keyed on `<strategy>` with 3 sibling
    bucket rows (`<sid>:bucket:0..2`); commit picks best avg_pnl bucket and
    nudges max-hold bars by ±10% of expected_holding_bars.
  - `scheduler.py` — `LearnerScheduler` runs all 3 in one cycle + evicts
    expired triple blocks. asyncio `run_forever(interval_sec=3600)` for
    hourly cron.
- **Layer 6 — Live Recalc stubs**: `polaris/core/live_recalc/`
  - `tick_recalc.py` — `mark_position_dirty` + `should_run_recalc` (5s cadence
    floor, dirty-trigger override) + `recompute_exit_params` P0 stub
    (logs `would_recalc`, clears dirty mark) + `run_live_recalc_cycle`.
  - `regime_flip.py` — `(venue × underlying_group_id)` SSOT, 2-consecutive
    close confirmation rule, `crisis` immediate flip, publishes
    `market_events.regime_flip` row.
  - `strategy_swap.py` — `entry_strategy_id` immutable / `active_strategy_id`
    mutable. `evaluate_strategy_swap` enforces max 1 swap/trade + same
    correlation_group; `apply=True` writes new segment row.
  - `conviction.py` — 4-gate stacking decision (cell-top + group-cap + ≥0.5R
    pnl + headroom>0), max 3 layers (1.0/0.7/0.5), wait when full
    (rotate forbidden).
- **7 P0 Strategies — signal generator only** (ADR-008): `polaris/strategies/`
  - `base.py` — `BaseStrategy` ABC + `RawSignal` + `StrategyMetadata` +
    `MarketView`/`BarView` projections.
  - 4 OKX SPOT: `volume_burst` / `tsmom` / `rsi_bb_pullback` / `spot_donchian`.
  - 3 Capital CFD: `fx_breakout_basket` (30×) / `xau_indices_trend` (20×) /
    `session_breakout` (20×).
  - `STRATEGY_REGISTRY` maps `strategy_id → class`; `all_strategies()` factory.
- **Schema additions** (`polaris/storage/schema.py` + idempotent
  `_apply_post_migrations`):
  - `learner_state` / `learner_blocks` / `learner_snapshot` /
    `rollback_candidates` (Layer 5).
  - `position_live_recalc_state` / `regime_state` (extended with
    `consecutive_candidate` + `consecutive_count`) / `position_conviction_layers`
    (Layer 6).
  - `positions.swap_count` ALTER (introduced for active/entry split).

## Codex external review

- **Round 1** (gpt-5.4): REJECT_WITH_FIXES — 4 issues:
  - **P0** `max_hold` started at 1.0 (NEUTRAL_MULT) instead of
    ``expected_holding_bars`` baseline → would collapse winner-hold to ~1
    bar once ``n_eff ≥ 20``.
  - **P1** ``commit_hourly`` candidate-row reads happened *before*
    ``BEGIN IMMEDIATE`` and snapshot ran *after* ``COMMIT`` — read-modify-write
    race with concurrent close writers.
  - **P1** ``strategy_swap`` only checked correlation_group + swap_count;
    never validated candidate ``venue / symbol / side`` against the live
    position row (Layer 6 Q3 invariant violation).
  - **P2** initial regime seed returned ``confirmed=True`` although
    docstring promised "first observation, no flip".
- **Round 2** (gpt-5.4): **APPROVE** — all four fixes verified:
  - ``MaxHoldLearner._upsert_state`` override now bypasses the [0.3, 3.0]
    multiplier clip (bars-valued state) + ``observe()`` seeds at
    ``expected_holding_bars`` when prior == NEUTRAL_MULT.
  - ``BaseLearner.commit_hourly`` and ``MaxHoldLearner.commit_hourly``
    moved every SELECT + UPDATE + ``_write_snapshot`` inside one
    ``BEGIN IMMEDIATE`` / ``COMMIT`` transaction.
  - ``evaluate_strategy_swap`` reads venue/symbol/side from the position
    row, returns ``skipped_position_mismatch`` when they diverge.
  - ``detect_regime_flip`` initial seed → ``confirmed=False, reason='initial_seed'``.
- 3 new regression tests cover all four paths
  (``test_max_hold_starts_from_expected_holding_bars``,
  ``test_strategy_swap_position_mismatch_blocks``,
  ``test_regime_flip_initial_seed_not_confirmed``).

## Aggressive-bias self-check

- Triple block applies as `size_mult=0.3` — entry **never blocked**, only
  attenuated, and auto-unblocks in 1h. No permanent winner-cuts.
- Conviction stacking = `wait` when capacity full (rotate forbidden);
  layer mults `(1.0, 0.7, 0.5)` keep first layer at full size.
- `max_hold` learner moves toward best-bucket bars but each hour at most
  ±10% of expected — no sudden choke on winners.
- 7 strategies frozen at v1 params (no defensive shrink); learner cell-mult
  delivers the only state-driven amplification path.
